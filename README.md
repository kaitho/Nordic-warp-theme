# Nordic Warp Theme

A dark Nordic theme for [Warp](https://www.warp.dev/), designed to match the Nordic setup used across KDE Plasma, Warp Terminal, and VS Code.

## Theme

- Background: `#2E3440`
- Foreground: `#D8DEE9`
- Accent: `#88C0D0`
- Blue: `#81A1C1`
- Green: `#A3BE8C`
- Red: `#BF616A`
- Yellow: `#EBCB8B`
- Magenta: `#B48EAD`

## Installation

Copy `themes/Nordic.yaml` to Warp's custom theme directory on Linux:

```bash
mkdir -p ~/.local/share/warp-terminal/themes
cp themes/Nordic.yaml ~/.local/share/warp-terminal/themes/
```

Restart Warp and select **Nordic** from the theme picker.
